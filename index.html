    三步做出一个网页

    1. 从左侧素材库把模块拖到中间画布（也可以直接点素材卡片）
    2. 点击画布上的模块，在右侧属性面板改文字、颜色、字号、留白
    3. 点右上角导出 HTML，得到一个可以双击打开、可直接上传托管的独立网页文件

    快捷键

    • Ctrl + Z 撤销
    • Ctrl + Y / Shift + Z 重做
    • Ctrl + D 复制选中模块
    • Delete 删除选中模块
    • Esc 取消选中 / 关闭弹层

    其它

    • 上传的图片会作为素材保存，也可直接把图片文件拖进画布
    • 项目自动保存在浏览器本地；「导出项目 JSON」可备份或换设备继续编辑
    • 顶部可切换桌面 / 平板 / 手机宽度，检查响应式效果
    • 导航栏的「滚动时吸顶」在预览和导出时对整个页面生效；若把导航栏放在容器里，预览和导出会自动把它提升到页面顶部，画布里可用属性面板的按钮一键移动
    • 上传的大图会自动等比压缩到 1600px 以内，页面里只保存素材引用，避免同一张图在项目 / 历史 / 导出文件里重复占用空间
    • 右侧设置项可用顶部搜索框直接定位；窗口较窄时「☰ 素材」和「⚙ 属性」会变成抽屉，点击画布上的模块会自动展开属性
    • 页面设置里可填写「网站描述（SEO）」，导出的 HTML 会带上分享信息、打印样式，并尊重系统的「减少动效」设置

    导入现有网页

    • 三个入口都一样：顶栏 ↥ 导入、右上 ⋯ → 导入 HTML 文件，或者直接把 .html 文件拖进画布
    • 选完文件先出一张摘要：识别出多少个模块、分别是哪几类（导航栏 / 主视觉区 / 标题 / 段落 / 卡片 / 引用 / 页脚）、有没有读不到的图片或外部样式
    • 确认时可选替换当前画布（页面配色、项目名也一起换）或追加到末尾；弹窗每次打开都回到「替换」，避免连点两次把内容翻倍，导错了 Ctrl + Z 一步退回
    • 能带过来：导航与菜单（原页面固定 / 吸顶的导航会一起带上，不会滚走）、主视觉（小标签 / 大标题 / 描述 / 按钮）、各级标题与段落、按原列还原的多列布局（图片 + 引文这种左右两栏、三张卡片并排都能对上）、图标卡片列表、引用（署名单独放，不会重复）、页脚链接与地址邮箱、纯色与渐变背景（linear / radial 都认），以及 data: 内嵌的图片
    • 原页面如果开场就是一块全屏幕（品牌名 + 副标题，或者一段视频），会认出来并在导入后还原成品牌幕 / 视频揭幕；一开始停在透明、等滚动才浮现的元素，也会按「动画播完」的样子导进来，不会整段消失
    • 带不过来：外部 CSS 文件里的样式（只拿到结构和文字，颜色字号要再过一遍）、复杂的绝对定位（会被拍平成模块顺序）、多图层叠加的纹理 / 图片背景（只留最底那层渐变）、相对路径的图片（需要重新上传）
    • 导入不会强行塞一个开场幕：原页面没有开场动画的，进来就是正常页面；需要的话再去「页面 → 开场动画」打开

    嵌套与容器 · 一行放多个模块

    • 拖入「容器 / 分组」或直接拖入「一行多列容器」，再把别的模块拖进去，就会并排放在同一行
    • 容器三种排列：纵向堆叠（上下排）、一行均分（等宽网格，可设一行放 1–6 个）、自动横排（按子模块宽度排，放不下自动换行）
    • 选中容器后，属性面板有「子模块排成一行 / 自动横排 / 纵向堆叠」三个一键切换按钮
    • 一行均分时，选中某个子模块可在「通用设置 → 尺寸与位置」里设横向占几列；自动横排时可设行内宽度（0 = 自动均分）
    • 还可设项目间距与垂直对齐；手机宽度下所有横向容器都会自动变成单列
    • 容器里还能再放容器；选中容器后点素材卡会直接加进它里面，层数不限
    • 拖动时金色虚框标示目标容器，金色竖线标示会插入到这一行的哪个位置

    图标与图片 · 表情组件都能换成图片

    • 卡片、三栏特性、要点清单、导航栏徽标、公告条、团队头像、用户评价头像、品牌墙、提示框、联系信息，凡是能填 emoji 的位置都能放图片
    • 选中模块后，右侧「图标 / 徽标」「头像」等字段点＋ 上传图片，或从下拉里选「我的图片」中的素材；也可直接粘贴图片网址
    • 多行列表（三栏特性、要点清单、团队成员、品牌墙、图片画廊）第一格填图片即可；属性面板有＋ 追加图片行，会自动加一行并填好图片
    • 上传的图片同时存进左侧「我的图片」，可重复使用；导出 HTML 时图片会内嵌，单文件即可独立打开
    • 删除「我的图片」里的素材时，页面里对它的引用会一并清除，不会出现破图

    模块通用设置

    • 每个模块的属性面板底部都有「通用设置」，分 5 组：链接与标识、尺寸与位置、边框与效果、进入动画、显示与高级
    • 链接打开方式可设：当前窗口 / 全部新标签页 / 仅外部链接新标签页；新窗口链接会自动带上安全属性
    • 调整大小：直接拖模块右下角的蓝色手柄，或在面板里精确设置宽度、最大宽度、最小 / 固定高度、外边距与水平位置
    • 锚点 ID 可用于 #锚点 跳转；还能加自定义 CSS 类、边框、投影、透明度、悬停效果和追加 CSS
    • 显示条件可设为「仅桌面 / 平板」或「仅手机」；设为「隐藏」时模块仍留在编辑器里，但不会写进导出的 HTML
    • 编辑器里的链接点击不会跳转，方便直接选中和调整模块

    滚动播放视频

    • 素材库「内容展示」里有滚动视频模块，内置 3 段演示素材（极光渐变 / 透视网格 / 界面演示），点一下就加进页面
    • 另有第 4 段「品牌揭示」：workrequirement 的 logo 揭示片，也能用在下面的视频揭幕开场里
    • 默认是随滚动播放：往下滚多少，视频就播到哪一帧；往回滚画面也跟着倒退，适合做产品演示和模板展示
    • 也能切成进入循环（滚到就自动循环播放，划走自动暂停）或点击播放（带浏览器原生进度条）
    • 换成自己的视频：填 mp4 / webm 直链，或点＋ 上传视频（建议 1.5MB 内，导出时会一起打包进单文件 HTML）
    • 画布上只显示封面，避免反复解码拖慢编辑；视频真正加载和播放只发生在「预览」和导出的页面里
    • 视频底部有一条细进度线，随滚动实时显示播到了哪里

    开场动画与滚动提示

    • 选中空白处打开页面设置，最上面是开场动画：进入网站时先盖一层整屏幕布（标题 + 进度条），再揭开显示页面，类似品牌官网的开场
    • 四种样式：品牌幕（淡出）、光标进入（白色光标滑到「进入网站」按钮上点一下再揭开）、幕布揭开（上下收拢）、视频揭幕（整屏放一段片子，往下滚多少就播到哪一帧，滚满一屏刚好播完，再揭开进正文）
    • 视频揭幕用的是同一个「滚动推进」引擎：光标位移、涟漪、底部进度线、片子画面全由滚动进度统一驱动，往回滚会倒放；滚到底或点一下也能直接揭开
    • 视频揭幕可以选内置的「品牌揭示」，也可以填直链或＋ 上传视频；画面用 contain 合入，竖屏手机上文案自动转成竖排，不会裁掉字幕
    • 可改幕上标题、副标题、幕布背景（支持渐变）；「揭幕推进」可选跟鼠标滚动（默认）或自动播放，自动播放时才有「停留时长」（0.6–5 秒）；播放频率分为每次 / 每会话一次 / 只播一次
    • 点击、滚轮或按任意键都能立刻跳过；系统开启「减少动效」时不播放，关闭 JS 时页面直接显示，绝不会卡在幕布上
    • 滚动提示：屏幕底部固定一枚小胶囊（滚轮鼠标图标＋「滑动鼠标」），滚轮线随真实滚动上下移动、停下回弹；滚过 90px 自动淡出，点击会往下翻一屏
    • 点「▶ 试播开场动画」可以在编辑器里直接看一遍完整效果，不用来回切预览

    动效与鼠标

    • 进入动画：每个模块的「通用设置 → 进入动画」可选 9 种效果（上移 / 下移 / 左右滑入 / 缩放 / 旋转 / 模糊聚焦 / 翻转 / 遮罩揭示），并单独设时长、延迟、缓动、位移距离、播放一次或每次进入
    • 滚动到可视区域才播放；点「▶ 在画布里试播」可以立刻看一遍，编辑器画布平时保持静止，方便排版
    • 容器还能设「子模块依次入场」，让里面的卡片一个接一个出现
    • 鼠标悬停：上浮、大幅上浮、放大、柔光发光、扫光掠过、3D 倾斜、描边高亮、光标光斑；常驻动效：上下浮动、呼吸缩放、光晕呼吸、流光扫过
    • 页面设置（不选中任何模块时）→ 动效与鼠标：动效强度（克制 / 标准 / 强烈）、光标光晕、跟随光标（圆环 / 圆点 / 两者）、磁性按钮、顶部滚动进度条、回到顶部按钮、尊重系统「减少动效」
    • 还有三个一键按钮：为所有模块加进场动画、卡片统一加悬停上浮、清除全部动效（Ctrl+Z 可撤销）
    • 以上效果在「◉ 预览」和导出的 HTML 里生效；系统开启「减少动态效果」或浏览器不支持时，页面直接呈现最终状态，内容不会消失

    渐变颜色

    • 所有颜色字段右侧有个 渐变 按钮，点开就是渐变编辑器：线性 / 径向 / 锥形三种类型，可选角度或直接点预设色板
    • 也可以直接在文本框里粘贴 CSS，例如 linear-gradient(135deg,#3b82f6,#8b5cf6)，写什么导出就是什么
    • 「恢复纯色」会退回起点色；渐变可以用于页面背景、区块背景、卡片、按钮、标签等所有背景类字段

    自定义组件

    • 存为组件：选中任意模块或容器 → 右侧属性面板最下面点「✚ 存为我的组件」→ 起个名字选个图标，它就出现在左侧「我的组件」里
    • 之后把组件拖到画布、或直接点一下即可插入；每次插入都是独立副本，改其中一个不会影响其他，也不会影响原始组件
    • 卡片右侧的 ✎ 可以重命名 / 换图标，✕ 删除组件（Ctrl+Z 可撤销）。组件库会随项目一起保存和导出 JSON
    • 自定义 HTML：素材库「自定义」分组里，可以直接写任意 HTML 和行内样式；出于安全，<script>、<style> 标签和 on* 事件属性会被自动移除（行内 style 保留）

    组件库（37 个）

    • 按 6 组分类：基础内容、导航与框架、内容展示、转化与互动、排版工具、自定义
    • 搜索框可按名称快速定位，点击分组标题可折叠该组
    • 导航栏可设置吸顶：在中间画布滚动时就会固定在顶部，导出的页面同样生效；还可设「吸顶距顶部」留出偏移
    • 吸顶的导航栏建议放在页面最外层（第一块）。若放在容器里，只能在容器范围内吸附，属性面板会提示并给出「移到页面最外层」按钮
    • 手机宽度下导航栏会自动变成可点击展开的菜单
    • 菜单、链接、价格、时间线等多行内容都用「每行一条、竖线分隔」的格式填写
